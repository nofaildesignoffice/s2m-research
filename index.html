0한 줄 결론

오션니치 올인은 “매출 타겟”이 아니라 “신뢰앵커 · 성분내러티브 · 진입문”으로만 유효하다. 상세페이지는 오션인을 hero로 세우되, 전환은 일반 구매자의 피부상태 자기선택으로 받아야 손익이 맞는다.

“내수 오션니치가 유효한 시장인가?”라는 핵심 질문에 데이터는 ‘제한적 유효’로 답했다. 오션 정체성은 브랜드의 심장으로 두되, 세일즈 엔진은 일반 구매자를 끌어들이는 구조여야 한다.

해양활동 여름 편중 → 가을·겨울 비수기 방어장치(실내수영·안티에이징 브릿지) 필요.

⚥ 성비

오션인 상당수 남성·뷰티 저관여 → 남녀공용·무향 설계 or 여성타겟 정교화.

💰 가격저항

다이아몬드 원가↑인데 소구 약하면 다이소 저가 VT와 평면비교 → 가격저항 깰 논리 필요.

🔁 주1회 LTV

5,000샷 1병 2~3달+ → 재구매 느림. 데일리 진정 크로스셀·세트구성을 상세페이지 단계부터.
가장 큰 단일 리스크 — 부작용 → 커뮤니티 퇴출. “바다 활동용”처럼 마케팅하면 소비자가 손상 직후(장벽붕괴·홍조)에 발라 접촉성 피부염·뒤집어짐 발생 가능. 좁은 버디·강사 네트워크 특성상 “이거 발랐다가 얼굴 뒤집어졌다” 소문 한 번이면 신뢰노드가 추천 철회 → 진입시장에서 영구퇴출.

6상세페이지 기획 함의

포지셔닝: “바다에서 시작됐지만, 바다에 가지 않아도 되는 — 물·자외선에 지친 피부의 주1회 회복 부스터.”
오션인 = hero · 신뢰앵커 · 성분내러티브 / 일반구매자 = 피부상태 자기선택 전환.

권장 구성 (감정곡선)

  1. 오션인의 극한 노출 장면 — 감각카피(당기고 달아오른 얼굴, 버디문화). Hero·정체성.
  2. 자기진단 다리 — “바다에 가지 않아도, 세안 후 심한 당김·거친 결·칙칙함·화장품 겉돎 중 2개면 당신도.” 일반구매자 포섭.
  3. 부스터 역할 교육(선택기준 교육) — 1등 경쟁 아닌 “기존 루틴 위 주1회 얹는 부스터”, 시너지.
  4. 시점분리 안전설계 — 현장 직후=진정·보습 / 스피큘=안정된 날 저녁 주1회. 홍조·상처·일광화상 시 사용금지 명시.
  5. 제품 기술·근거(규제안전) — 각질정돈·특허스피큘·다이아몬드 25ppm 함유 + 완제품 성적서 확인분만 시험조건 병기.
  6. 신뢰근거 — 강사·오션인 리뷰(커뮤니티=신뢰), 원료 산지·채취(해양보호를 스토리 아닌 증거로).
  7. CTA + 세트·재구매 설계 — 데일리 진정 크로스셀, 체험분 진입장벽↓, 비수기 브릿지.

7전략 결정 · 데이터 공백

데이터·근거·선택지는 정리했으나 결론은 못박지 않음 — 대표·리건 판단 영역.

1. 다이아몬드 컨셉
소구 약함 판명. 제품명은 유지하되 상세페이지 hero를 “회복·장벽” 서사로 옮길까?
2. 안전 프레이밍
“고자극→회복” 서사가 부작용 리스크의 방아쇠. 시점분리·사용금지 조건을 얼마나 전면에? (신뢰 vs 매력 트레이드오프)
3. 성비 · 계절성
남녀공용 설계 여부, 비수기 매출 브릿지.
4. 세트 · 가격
다이소 저가 VT 대비 가격저항 + 주1회 LTV → 세트/구독 구조.

데이터 공백 (보강 권장)

  • 프리다이버·강사·항해사 정확 국내 인구·뷰티지출 → 웹 불가, 강사 인터뷰·커뮤니티 설문으로 보강.
  • 완제품 임상·기능성 증빙 → 대표 제출(위 필수 증빙 리스트).
  • 실제 판매 전환율 → 대표측 데이터 없음.
